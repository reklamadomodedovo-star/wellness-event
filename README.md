# WELLNESS EVENT — информационный портал о событиях в сфере ЗОЖ

Интерактивный прототип wellness-портала по ТЗ: новости, календарь событий, обзоры прошедших мероприятий, полезные статьи, курсы и обучение, плюс каталог компаний и сообщество на перспективу.

## Страницы

| Страница | Описание |
|---|---|
| [`index.html`](index.html) | Интерактивный прототип (10 экранов): Главная, Новости, Wellness календарь, Обзор мероприятий, Полезное (статья), Курсы и обучение, Админка, WP-реализация, Матрица соответствия ТЗ, плюс заглушки «Каталог/Сообщество — скоро». |
| [`report.html`](report.html) | Аналитический отчёт (исследование рынка и поведения читателя). |

## Что внутри

- **Бренд:** WELLNESS EVENT, палитра «зелёный (изумрудный) · чёрный · крем-бежевый», тёплый wellness-дизайн.
- **Wellness календарь enlarged на главной** справа от картины дня; иконки типов событий в ячейках (🏃 бег, 🧘 йога, 🥗 питание, 🎤 лекция, 🚴 велосипед, 🌿 медитация, 🏊 плавание).
- **Wellness-bar** вместо валют: комфорт для пробежки, УФ-индекс, восход, фаза луны.
- **11 событий** в календаре: фестивали, забеги, лекции о питании, велопробег, йога-ретрит, заплыв, старт курса.
- **6 курсов** с фильтрами по направлению, формату (онлайн/офлайн/гибрид) и цене.
- **6 отчётов о прошедших мероприятиях** с фото-карточками, отзывами и рейтингами.
- **Реклама:** нейтральные блоки с тонкой рамкой, 5 зон, разметка по тумблеру «Разметка рекламы».
- **Адаптив:** «Компьютер 1280 / Планшет 834 / Телефон 390» — переключатель в шапке, на телефоне бургер-меню.
- **Живые механики:** счётчики, «сейчас читают», тёмная тема, прогресс чтения, липкая шапка, анимации (можно отключить через `prefers-reduced-motion`).
